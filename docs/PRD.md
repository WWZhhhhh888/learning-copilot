# 凑单助手 - 产品需求文档 V1.0

## 一、产品概述

| 项目 | 内容 |
|------|------|
| 产品名称 | 凑单助手 |
| 产品定位 | 基于飞书/微信群的凑单机器人 |
| 目标用户 | 大学生、办公室白领 |
| 核心价值 | 让凑单从“手动麻烦”变成“自动简单” |

## 二、用户需求（基于调研数据）

| 优先级 | 需求 | 用户比例 |
|--------|------|----------|
| P0 | 自动统计谁点了什么 | 72% |
| P0 | 自动计算人均 | 69% |
| P1 | 支持多人同时加单 | 66% |
| P1 | 凑满后自动提醒 | 45% |

## 三、功能列表

| 优先级 | 功能 | 触发词 | 输出 |
|--------|------|--------|------|
| P0 | 发起凑单 | `我要凑单，目标XX元` | 创建会话，返回状态 |
| P0 | 添加订单 | `+商品名，XX元` | 累加金额，返回状态 |
| P0 | 查看状态 | `凑单状态` | 返回明细+进度 |
| P0 | 自动算人均 | 总额>=目标时触发 | 返回人均金额 |
| P1 | 凑满提醒 | 总额>=目标时触发 | 自动通知所有人 |
