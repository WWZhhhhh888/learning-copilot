# 凑单助手 - 竞品分析

## 一、竞品对比

| 竞品 | 优点 | 缺点 | 机会点 |
|------|------|------|--------|
| 微信群手动 | 零门槛、人人会用 | 手动统计慢、容易乱、无提醒 | 用机器人替代人工 |
| 美团/饿了么拼单 | 官方支持、自动算钱 | 仅限同店、不能跨店 | 跨店凑单 |
| 拼单小程序 | 功能完整 | 需下载、用户少 | 嵌入群聊、无需下载 |

## 二、用户痛点（问卷数据）

- 34%的人觉得“找人拼单”最麻烦
- 24%觉得“计算人均”最麻烦  
- 38%经历过“凑半天没凑够”

## 三、产品定位

> 在微信群内，零门槛使用，自动统计、自动算钱、自动提醒。

## 四、功能优先级

| 优先级 | 功能 | 用户需求度 |
|--------|------|-----------|
| P0 | 自动统计 | 72% |
| P0 | 自动算人均 | 69% |
| P1 | 多人加单 | 66% |
| P1 | 凑满提醒 | 45% |
